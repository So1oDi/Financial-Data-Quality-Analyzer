# Демонстраційні дані

`sales_reference_1000.csv` та `sales_damaged_1000.csv` — приклади для сценарію ручного імпорту. У програмі доступна генерація пар на 1 000, 10 000 та 100 000 еталонних записів. Пошкоджена копія має на 2% більше рядків через навмисні дублікати.

Відтворення прикладів і таблиці вимірювань з кореня проєкту:

```powershell
.\.venv-fin\Scripts\python.exe -m utils.run_experiment
```
