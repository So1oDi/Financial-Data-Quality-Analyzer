# Метрики якості

Для оцінки ефективності частка збереження дорівнює 100 × прийняті рядки / вхідні рядки. Абсолютне відхилення — |показник − еталон|. Відносне — 100 × абсолютне відхилення / |еталон| за ненульового еталона. MAE = mean(|y−ŷ|), RMSE = √mean((y−ŷ)²), R² = 1 − Σ(y−ŷ)²/Σ(y−ȳ)². За нульового розкиду тесту R² недоступний.

Усі доступні оцінки належать проміжку 0–100%. Оцінка з нульовим знаменником має статус «Недостатньо даних».

| Метрика | Формула | Вага | Обґрунтування |
|---|---|---:|---|
| Повнота | `100 × (C − M) / C` | 20 | Для `C` комірок рахуємо `M` пропусків, включно з порожнім і пробільним текстом. |
| Унікальність | `100 × (N − D) / N` | 15 | `D` — кількість рядків у об’єднанні повторних повних і ключових входжень серед `N` рядків. Пропуски ключа не утворюють ключових дублікатів. |
| Валідність | `100 × (V − B) / V` | 20 | Для `V` застосовних перевірок типів, адрес, дат та обмежень рахуємо `B` порушень. Пропуски враховує повнота. |
| Узгодженість | `100 × (S − F) / S` | 15 | `S` — кількість застосовних перевірок пробілів та словників категорій, `F` — кількість порушень. |
| Точність | `100 × A / R` | 20 | `R` — заповнені спільні неключові комірки еталона з повним ключем, `A` — рівні значення, для яких є один збіг ключа. Відсутні та неоднозначні збіги дають нуль успішних порівнянь для відповідного рядка. |
| Своєчасність | `100 × T / N` | 10 | `T` — кількість дат від дати оцінки мінус допустимий вік до дати оцінки включно. Некоректні, відсутні, майбутні та старі дати не входять до `T`. |

Для точності потрібні еталон, спільні поля та унікальний заповнений ключ у порівнюваній частині еталона. Порівняння комірок використовує рівність значень pandas. Відформатоване інакше значення може потребувати спільної стандартизації обох таблиць. Своєчасність потребує вибраного поля, параметрів оцінки та щонайменше однієї розпізнаної дати. Дати з часовими зонами зводяться до UTC.

Інтегральна оцінка дорівнює `Σ(wᵢ × qᵢ) / Σ(wᵢ)` за доступними метриками. Вищі ваги мають повнота, валідність і точність через їх прямий вплив на висновки. Ваги є проєктним припущенням для курсової. Порівняння до і після використовує одну конфігурацію, а доступність окремих метрик може змінюватися після очищення. Відносна зміна дорівнює `100 × (після − до) / до` за додатної початкової оцінки.

Аномалії відображаються в журналі проблем, оскільки статистична незвичність сама по собі не підтверджує помилку.
