# Фінальна перевірка

CPython 3.15.2, Windows x64, середовище .venv-fin. Команда `.venv-fin\Scripts\python.exe -m pytest -q` дала **34 passed, 1 warning in 22.45s**. Попередження походить від застарілої стратегії SQLAlchemy у MLflow.

- Streamlit AppTest проходить усі 14 розділів, перевіряє фінансову та звичайну таблиці, обидві ML-сторінки, керування версіями й окремий дашборд ефективності.
- Всі п’ять варіантів експорту перевірено через інтерфейс. XLSX прочитано OpenPyXL, три CSV — pandas, у HTML перевірено вміст звіту. Окремі тести перевіряють екранування й захист від формул.
- Двічі завантажено той самий робочий знімок. 940 рядків mart.operations збігаються за всіма полями із початковим станом після кожного запуску. У схемі є шість FK, у карантині 70 записів, 10 прийнятих платежів у списку звірки.
- Перевірено конфлікт суми за ідентифікатором, обґрунтування карантину, збереження великого платежу та незалежність статистичних сигналів.
- Перевірено часові межі трьох блоків, підбір за MAE, календарні ознаки, базовий і рекурсивний прогноз, підтримку первісного формату моделі.
- HTTP API локального MLflow показав 13 версій кожної з двох моделей. Після копіювання реєстру та артефактів до іншої папки всі 26 версій успішно завантажено, кожна повернула скінченні результати inference.
- Для обсягів 1 000, 10 000 та 100 000 запущено повний експеримент, збережено 72 рядки валідації (4 моделі × 3 блоки × 2 стани × 3 обсяги).
