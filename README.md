# Financial Data Quality Analyzer

Локальна аналітична система для курсової роботи «Якість даних як ключовий чинник ефективності аналітичних систем: моделі, метрики, методи підвищення».

Імпортує CSV/XLSX, розраховує шість характеристик якості, показує місця порушень, дає попередньо перевірити обрані операції очищення, порівнює результати та експортує дані й звіти. Обчислення виконуються на комп’ютері користувача.

## Запуск у Windows

Фінальна версія порівнює чотири прогнозні методи за хронологічною валідацією. Повний звіт і результати незалежного тесту наведено в [FINANCIAL_REPORT.md](docs/FINANCIAL_REPORT.md).

Практичний варіант №7 додає збір фінансових транзакцій, ETL, постійну вітрину DuckDB, аналіз касової рентабельності, Isolation Forest і прогноз потоку на 7 та 30 днів. Розділи загального аналізу підтримують попередній сценарій із продажами та довільні таблиці.

1. Потрібен 64-бітний CPython. Проєкт перевірено на Python 3.15.2. У папці проєкту запустіть `setup.bat`, щоб створити `.venv-fin` і встановити пакети. Для першого встановлення потрібен доступ до PyPI.
2. Запустіть `start.bat` і відкрийте [локальний інтерфейс](http://127.0.0.1:8501), якщо вкладка не відкрилася автоматично.
3. Завершіть роботу через Ctrl+C у вікні сервера.

Для демонстрації завантажте 1 000 продажів, перегляньте проблеми, побудуйте попередній перегляд із готовим пакетом очищення, застосуйте його та запустіть вимірювання у розділі «Ефективність аналітичних систем».

## Перевірка та відтворення

```powershell
.\.venv-fin\Scripts\python.exe -m pip check
.\.venv-fin\Scripts\python.exe -m pytest -q
.\.venv-fin\Scripts\python.exe -m utils.run_experiment
.\.venv-fin\Scripts\python.exe -m finance.research
```

## Відтворення локального сховища та моделей

Репозиторій містить вихідний код, синтетичні демонстраційні CSV, тести та збережені результати експериментів. Локальні файли DuckDB і реєстру MLflow не публікуються. Для створення вітрини виконайте повний ETL, для реєстрації моделей — навчання у відповідних розділах програми. Історичні версії моделей у новому локальному реєстрі не відновлюються автоматично.
